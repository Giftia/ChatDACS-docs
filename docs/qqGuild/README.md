# 如何接入 QQ 频道机器人 <Badge text="注意" type="error"/>

::: danger 注意
目前 `QQ频道机器人账号` 有无法发送图片的问题，暂时不建议使用。推荐直接将机器人 QQ 加入到频道，除了频道权限功能之外，别的功能都可以正常使用。
:::

::: tip 提示
这个教程适用于想要小夜接入 `QQ频道机器人账号` 的用户。

小夜原生支持接入 QQ 内置的 `QQ 频道` ，即显示在 QQ 客户端的 `频道` 入口，只要小夜当前登陆的 QQ 账号以 `普通成员` 身份加入了 QQ 频道，即可在频道内使用。

对于大多数情况而言，其实并不需要申请频道官方的机器人账号，无需再配置单独接入 QQ 频道。

`QQ频道机器人账号` 和 `普通成员账号` 的一眼区别见下图。`QQ频道机器人账号` 有更高的权限，以及机器人标识和相关功能的体现。

## 第一步 创建 QQ 频道机器人账号

### 首先进入 QQ 开放平台

[QQ 开放平台](https://q.qq.com/)

### 注册并登陆 QQ 开放平台

请按这个文档进行操作：[注册开放平台账号](https://q.qq.com/wiki/#%E6%B3%A8%E5%86%8C%E5%BC%80%E6%94%BE%E5%B9%B3%E5%8F%B0%E8%B4%A6%E5%8F%B7)

## 第二步 配置并获取机器人账号

请按这个文档进行操作：[创建机器人](https://q.qq.com/wiki/#_3-1-%E5%88%9B%E5%BB%BA%E6%9C%BA%E5%99%A8%E4%BA%BA)

## 第三步 配置机器人服务

打开 `config` 文件夹内的 `config.yml` 配置文件，打开 **接入QQ频道开关** `CONNECT_QQ_GUILD_SWITCH`，将从 QQ 开放平台 获取的 `BotAppID` 和 `BotToken` 填入配置文件中的对应配置项 `QQ_GUILD_APP_ID` 和 `QQ_GUILD_TOKEN`，然后保存文件。

## 第四步 测试功能

启动 `chatdacs`，应该会显示 `小夜QQ频道接入开启`，以及成功连接 QQ 频道接口的响应。将机器人拉入你自己的测试频道即可测试功能。

## 频道私信

此入口指用户在 QQ 频道里点击机器人头像后进入的私信，不是 QQ 消息列表里的单聊。
新版可显式开启频道私信，默认关闭，以免改变现有频道事件订阅和权限要求：

```yaml
System:
  CONNECT_QQ_GUILD_SWITCH: true

qqBot:
  QQ_GUILD_DIRECT_MESSAGE_SWITCH: true
```

凭据仍使用现有 `ApiKey.QQ_GUILD_APP_ID`、`ApiKey.QQ_GUILD_TOKEN`。
开启后额外订阅 `DIRECT_MESSAGE`；平台需要允许该机器人接收私信，沙箱用户也需在对应范围内。
私信回复使用事件中的私信会话 `guild_id` 和触发消息 `msg_id`，不会发回普通文字子频道。

私信的插件与会话状态分别隔离，默认只允许 `ping`、`help`；帮助只列出本通道允许的插件。
审核过的插件可通过 `qqOfficial.pluginAllowlist` 配置，此列表同时用于新官方通道和频道私信。
频道文字消息的原有插件范围不受这一列表影响。
未命中插件时交给小夜聊天核心；私信普通聊天不使用频道随机回复概率。
当前只发送文本，不兼容的媒体返回会给出提示；不会发送空内容或 `undefined`。

同一私信会话串行处理，最多 1 条运行、3 条排队，全局最多 32 条在途消息。
进程内最多保存 1000 个去重标记，标记有效 5 分钟；重启后不保留去重记录。
插件沿用软超时，聊天等待上限 12 秒。私信 HTTP 发送上限 10 秒，超时取消请求，
但网络中断时不能保证平台尚未接收，因此不自动重试或重放插件。停止连接时取消在途私信请求，
不再处理排队消息和迟到回复，并禁用旧 SDK 的断线重连。

### 私信验收

先在频道文字子频道验证 `/ping` 和普通聊天，再从机器人头像进入私信，分别发送 `/ping`、
`/help` 和一句普通聊天。核对程序入站、发送成功和手机显示三个结果，不能仅凭 READY 判定通过。
同时确认频道原有消息仍正常，私信没有串到频道里。

如果频道正常而私信没有事件，优先核对 `DIRECT_MESSAGE` 权限、沙箱私信用户配置及入口类型。
当前频道 Adapter 沿用沙箱环境，必须在开放平台“沙箱配置 → 在频道私信配置”中添加测试 QQ 号；
仅配置沙箱频道不能代替私信账号配置。参见 [官方沙箱说明](https://github.com/tencent-connect/bot-docs/blob/main/docs/README.md#721-添加到沙箱频道)。
不要把它当成 QQ 单聊的 `C2C_MESSAGE_CREATE`；后者使用新官方 SDK 和 access-token 鉴权。
详情见 [官方私信接口](https://bot.q.qq.com/wiki/develop/api-v2/server-inter/channel/message/dms.html)。
